## Project Description

A comparison of steganography embedding and detection across JPEG and PNG image formats. PNG is lossless, so a hidden message survives encoding intact, which should make it marginally easier to detect. JPEG compression may inadvertently obscure a hidden message. The core research question is: does JPEG compression accidentally conceal steganography?

We will apply the same off-the-shelf embedding and detection tools to both formats and measure detection rates. If detectability differs between formats, that tells forensic analysts which format warrants closer scrutiny. If it turns out the same, that result is equally interesting.
